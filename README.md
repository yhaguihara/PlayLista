# 🎵 PlayLista — Playlist de Músicas

Um projeto web desenvolvido para reunir músicas de diferentes artistas em uma única página, permitindo ouvir prévias de áudio e acessar as faixas diretamente pelo Spotify.

## 🌐 Demonstração

**Acesse o projeto online:** [PlayLista](https://playlist-pi-ten.vercel.app/)

## 📖 Sobre o projeto

O **PlayLista** é um projeto desenvolvido com o objetivo de praticar os fundamentos do desenvolvimento web utilizando HTML e CSS.

A página apresenta uma coleção de músicas organizadas por artistas, com imagens, títulos e controles de reprodução de áudio. Além disso, permite acessar artistas e músicas no Spotify por meio de links integrados à interface.

## ✨ Funcionalidades

- 🎧 Reprodução de músicas por meio de controles de áudio.
- 🖼️ Exibição de imagens relacionadas às músicas.
- 🎤 Organização das músicas por artistas.
- 🔗 Links para músicas e perfis de artistas no Spotify.
- 🎨 Interface personalizada com estilização em CSS.
- 🔤 Utilização de fontes personalizadas do Google Fonts.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo da página.
- **CSS3:** estilização dos elementos e personalização da interface.
- **Google Fonts:** utilização de fontes personalizadas.
- **Spotify:** links externos para acesso às músicas e aos artistas.

## 📂 Estrutura do projeto

```text
PlayLista/
├── css/
│   ├── Style.css
│   ├── musica.css
│   ├── imagem.css
│   └── titulo.css
├── img/
│   └── Imagens das músicas

└── index.html
```

## 🚀 Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/yhaguihara/PlayLista.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd PlayLista
   ```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para executar a versão local básica do projeto.

## 🎯 Objetivo de aprendizagem

Este projeto contribuiu para o desenvolvimento de conhecimentos em estruturação de páginas HTML, estilização com CSS, organização de arquivos, utilização de recursos multimídia e integração com links externos.
